## Evidence policy

- A passing TypeScript/Python regression suite or ARM64 Debug build is automated evidence only.
- A successful Release signature check proves the APK was signed by the configured certificate; it does not prove install-over-upgrade compatibility on the user's device.
- No production signing key is rotated, removed from user control, or replaced without an explicit migration decision.
- Items marked OPEN/PARTIAL remain visible; they are not silently treated as completed.
